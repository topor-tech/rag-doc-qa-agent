# Корпоративный глоссарий

Одна строка — одно понятие. Слева сокращение, справа полная форма и синонимы.
Сокращение, полная форма и английский синоним означают одно и то же.
Сокращения чувствительны к регистру: ПО, ТП, КП, ЗП, КИ, СБ — это термины только в таком написании.
Если в вопросе одна форма, ищи в документах и остальные формы тоже.

АМ = Аккаунт-менеджер
АП = Администратор проекта
БПМ = Бизнес-процессы; должность: Директор по БПМ
БИФ = Бюджет внутреннего финансирования
BDM = Business Development Manager
ЦК = Центр компетенций
ДРП = Департамент работы с подрядчиками
ДС = Дополнительное соглашение
ДЭБ = Департамент экономической безопасности
ДИБ = Дирекция информационной безопасности
ЗИП = Запасные части, инструменты и принадлежности
ЗНП = Заявка на пресейл
ЗНИ = Запрос на изменение
ЗП = Заказ покупателя
ГИП = Главный инженер проекта
КСУП = Корпоративная система управления проектами; то же: ИСУП
КС-2 = Акт о завершении работ (форма); вместе с КС-3
КС-3 = Акт о завершении работ (форма); вместе с КС-2
КП = Коммерческое предложение
КИ = Кредитная история
НМЦК = Начальная максимальная цена контракта
ОПЭ = Окончательная приёмка/эксплуатация; документ: Протокол ОПЭ
ПА = Пресейл-архитектор
ПГ = План-график
ПМИ = Программа и методика испытаний
ПСИ = Приёмосдаточные испытания
РП = Руководитель проекта; то же: project manager
РСП = Руководитель сервисного проекта
РМ = Ресурс-менеджер
РТЗ = Расчёт трудозатрат
СБ = Служба безопасности
СРО = Саморегулируемая организация
SS = Solution Sales
SLA = Service Level Agreement
TSS = Technical Solution Sales
ТЗ = Техническое задание
ТКП = Технико-коммерческое предложение
ТМЦ = Товарно-материальные ценности
ТП = Техническая поддержка
УИБ = Управление информационной безопасности
УПД = Универсальный передаточный документ
ФТТ = Функционально-технические требования
ФОТ = Фонд оплаты труда
ФГ = Функциональная группа
HW = Hardware; то же: оборудование
ПО = Программное обеспечение
NDA = Non-Disclosure Agreement; то же: соглашение о неразглашении
RFI = Request for Information
FTE = Full-Time Equivalent; то же: полная занятость
