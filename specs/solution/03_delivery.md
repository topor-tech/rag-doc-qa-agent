# Опишите состав поставки и среду запуска. Приведите пример запроса и ожидаемого ответа. Если для входа на стенд нужен логин — укажите тестовый доступ.

Поставка состоит из трёх приложений и корпуса документов. Стенд — https://rag.topor.tech. Входа по логину нет.

**Состав.** Каталог `front` — интерфейс чата и читалка регламентов. Каталог `back/chat` — сессии и вызов модели. Каталог `back/knowledge` — загрузка документов и поиск. В `data/knowlage_files` лежат четыре регламента и глоссарий. Ключ модели в репозиторий не входит: локально он лежит в `back/chat/secrets/env` (`REG_CLOUD_CHAT_API_KEY`), на стенде его подставляет секрет GitHub Actions с тем же именем.

**Локальный запуск.** Нужны Python 3.14, uv, Node.js и PostgreSQL 18 на `localhost:5432`, база `rag`. Сервис знаний слушает `127.0.0.1:8001` и при старте сам накатывает схему и читает markdown. Чат слушает `127.0.0.1:8000`. Фронтенд открывается через Vite на порту 5173 и проксирует `/api` на чат. Модель `deepseek-v4.1-flash` вызывается по `https://ai.reg.cloud/v1`. Сессии и посетители лежат в Postgres, схема `chat`. Владельца диалога отмечает cookie `chat_visitor`.

**Стенд.** `docker-compose.prod.yml` поднимает Postgres 18, сервис знаний, чат и nginx с собранным фронтендом. Из контейнеров наружу опубликован только фронт, на `127.0.0.1:7000`. Nginx на сервере принимает `https://rag.topor.tech` (сертификат Certbot) и проксирует на этот порт. Страница и `/api/` открываются с одного имени: nginx внутри образа фронтенда пересылает `/api/` в чат. Сборку стенда делает workflow Deploy на self-hosted runner: `docker compose -f docker-compose.prod.yml up -d --build --remove-orphans`.

**Пример.** Вопрос: «Могу как SS отправить официальный оффер без согласования с архитектором?» Ожидаемый ответ: нет, кроме перепродажи вендорского сервиса или продажи пакетных предложений; иначе нужно согласование с пресейл-архитектором. Источник — пункт 2.3 регламента пресейловой деятельности Дирекции ИБ, ссылка вида `[2.3](/kb/presales-activity-ib#s-2)`.

**Доступ.** Логина нет. Чат на стенде открывается по https://rag.topor.tech. Локально — по адресу Vite.
