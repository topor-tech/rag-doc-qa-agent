# Укажите модели, среду их выполнения, фреймворки, базы данных и хостинг.

Модель одна: **deepseek-v4.1-flash**. Чат вызывает её по OpenAI-совместимому API `https://ai.reg.cloud/v1` — и чтобы переписать вопрос в поисковые слова, и чтобы написать ответ. Веса в этом контуре не загружаются, эмбеддингов и реранкера нет. Лемматизация запроса и пунктов идёт локально в процессе базы знаний: **pymorphy3** на CPU, словарь OpenCorpora.

Среда приложения — **Python 3.14** и **Node**. Чат (порт 8000) и сервис знаний (порт 8001) — **FastAPI** и **uvicorn**. Знания: **SQLAlchemy 2**, **Alembic**, драйвер **psycopg**. Тот же поиск отдан по **MCP** (`/mcp`); ход чата ходит в сервис по HTTP. Интерфейс — **React 19**, **Vite 8**, ответы рисует **react-markdown**.

База — **PostgreSQL 18**, база `rag`. Схема `knowledge` хранит документы, разделы, пункты и синонимы глоссария. Схема `chat` хранит посетителей, сессии и реплики. Локально база на `localhost:5432`.

Стенд — один Linux-сервер. `docker-compose.prod.yml` запускает Postgres, чат, сервис знаний и фронтенд. Фронтенд слушает только `127.0.0.1:7000`. Nginx на хосте отдаёт `https://rag.topor.tech` (сертификат Certbot) и проксирует на этот порт. В облаке только вызов модели.
