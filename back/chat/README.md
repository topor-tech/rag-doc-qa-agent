# Chat

FastAPI-бэкенд чата. Сессия хранит реплики в памяти и отправляет их в модель `deepseek-v4.1-flash` через `https://ai.reg.cloud/v1`.

Нужны Python 3.14 и [uv](https://docs.astral.sh/uv/).

## Секреты

Ключ лежит в `secrets/env` (файл в `.gitignore`):

```
REG_CLOUD_CHAT_API_KEY=sk-...
```

При старте приложение читает его, если переменная `REG_CLOUD_CHAT_API_KEY` ещё не задана в окружении.

## Запуск

```powershell
uv sync
uv run python -m chat.main
```

Сервер слушает `http://127.0.0.1:8000`. Интерактивная схема: `http://127.0.0.1:8000/docs`.

Фронтенд в `front` проксирует `/api` на этот адрес.

Одиночный запрос без сервера: `uv run python chat/example.py`.

## API

| Метод | Путь | Описание |
| --- | --- | --- |
| `GET` | `/health` | Проверка, что сервер жив |
| `POST` | `/sessions` | Новая сессия |
| `GET` | `/sessions/{id}` | История сессии |
| `POST` | `/sessions/{id}/messages` | Сообщение пользователя и ответ модели |

Тело сообщения:

```json
{ "content": "Кто подписывает агентский договор?" }
```

Ответ сессии:

```json
{
  "id": "7b7c5028-de0c-4228-aa96-6b1e618b774d",
  "messages": [
    { "role": "user", "content": "Кто подписывает агентский договор?" },
    { "role": "assistant", "content": "..." }
  ]
}
```

Неизвестная сессия возвращает `404`. Пустое сообщение — `422`. Ошибка модели — `502`. Сессии пропадают при перезапуске процесса.
